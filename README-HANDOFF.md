# Sellsuki Clinic V3 — ทีมส่งต่อ

## Preview สำหรับทีม

เปิดดูหน้าเว็บได้โดยไม่ต้องล็อกอินที่:

https://sellsuki-clinic-v3.beernat.chatgpt.site

## จุดที่แก้ไขหลัก

- โครงสร้างหน้า sale page สำหรับคลินิกความงามและสุขภาพ
- ไม่มี section “ทีมงานที่เชี่ยวชาญการตลาด และการเติบโตของธุรกิจคลินิก”
- ตัวอย่าง Local SEO ใช้ภาพแผนที่ mockup ของกรุงเทพฯ
- ตัวอย่างความน่าเชื่อถือใช้ภาพคุณหมอหญิงทำ HIFU
- ตัวอย่าง LINE แสดงการจัดกลุ่ม “สนใจ แต่ยังไม่นัด”, “เคยใช้บริการแล้ว”, และ “ถึงรอบติดตาม”

## ไฟล์ที่ควรแก้

- `app/page.tsx` — ข้อความ โครง section และองค์ประกอบหน้า
- `app/globals.css` — layout, สี, responsive และ style ของ mockup
- `public/` — โลโก้ ภาพประกอบ และ asset ทั้งหมดของหน้า

## เปิดงานต่อในเครื่อง

1. ติดตั้ง Node.js 22 ขึ้นไป
2. รัน `pnpm install`
3. รัน `pnpm build` เพื่อตรวจการ build
4. รัน `pnpm dev` เพื่อเปิดแก้ไขในเครื่อง

ฟอร์มในหน้าเป็น mockup และยังไม่มีการส่งข้อมูลไปยังระบบใด
